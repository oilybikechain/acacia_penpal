# Private organiser notes

Do not distribute this file, source code, or private exports to participants.

Codes contain four numeric characters, including possible leading zeros. The **third digit from the left** encodes the house:

| House | Allowed third digits |
|---|---|
| Aeon | 0, 1 |
| Genesis | 2, 3 |
| Nous | 4, 5 |
| Telos | 6, 7 |
| Zenith | 8, 9 |

Each house has 2,000 possible codes. Codes are unique across the roster and are identifiers, not registration passwords. Registration uses the Telegram account and survey handle, with admin-assisted linking when needed. Participant help, responses, and errors never explain this encoding. The house hint simply returns the penpal's house; it does not describe the code rule.

Names, gender, year, and major remain absent from assignment messages, but participant-authored nicknames and notes may reveal them. Review every introductory note in `/pairs` or the launch preview.

Keep the admin bot link and allowlist under organiser control. Knowledge of the admin bot's username alone does not grant access: every update is checked against numeric Telegram user IDs.
